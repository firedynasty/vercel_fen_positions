Chess Position Saver

Build and save chess positions with FEN notation

Supabase Puzzles
Source of truth: Dropbox /study/chess/<category>.csv (fen,note). Reorder, edit notes or delete there, then Sync. Save and Delete here update the CSV too.
Deep link a puzzle: append ?id=<id> or just ?<id> to the URL — auto-loads on page open. Otherwise the category dropdown fills in normally, but no puzzle loads onto the board until you pick one.
💾 Save to Dropbox + Supabase copies the FEN (or loaded PGN) to both: a new line at the end of /study/chess/<category>.csv and a new Supabase row with a new id. It never replaces a line, so saving the same FEN twice gives two lines.
Delete a line in the CSV, then ⇅ Sync from Dropbox: Sync sees that FEN is in no CSV and asks first, e.g. "Deleting (not in any CSV): #42 mate_in_5: win the queen". OK deletes it from Supabase; Cancel changes nothing.
A ?id= link to a deleted puzzle stops working ("Puzzle not found"). Cutting a line into another CSV is a move, not a delete: same id, new category.

How to use

                    

                        🎤 Spoken — F3, speak, F3, paste, += Apply

                        ⌨️ Typed — type SAN directly, += Apply
                    

                    
🎤 Spoken samples (whisper-friendly):

                    D4, Knight F6, Knight F3, G6, E3
                    Bishop G7, Bishop E2, Castles, Castles
                    D takes E5, Queen takes D1, Rook E8
                    casos / casuals / costing → castles
                    9 to F6 → Nf6   text D1 → takes D1
                    
⌨️ Typed samples (fill-in gaps):

                    Qxd1,Rxd1,Re8,Nc3,c6
                    1.e4 e5 2.Nf3 Nc6 3.Bb5
                    O-O   O-O-O   dxe5   Bxf7+
